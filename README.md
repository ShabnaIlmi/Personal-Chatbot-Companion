# Personal AI Companion Chatbot

## Overview
The **Personal AI Companion Chatbot** is an advanced AI-powered conversational assistant built using the **Llama 3.3-70B-Versatile** model. This chatbot leverages the **Groq API** to deliver highly personalized and context-aware interactions, providing users with a seamless and engaging conversational experience.

## Features
- **Conversational AI**: Leverages Llama 3.3-70B-Versatile for intelligent and context-aware responses.
- **API Integration**: Utilizes the Groq API for processing and delivering AI-generated replies.
- **Personalization**: Adapts to user inputs, maintaining context for a more natural conversation flow.
- **Web-based Interface**: Hosted on **Streamlit**, providing an intuitive and user-friendly chat experience.s
- **Real-time Processing**: Delivers responses with minimal latency for smooth interactions.

- **Llama 3.3-70B-Versatile** (AI Model)
- **Groq API** (Processing and AI inference)
- **Streamlit** (Web UI framework)
- **Python** (Backend development)

## Installation & Setup
If you'd like to run your own instance of the chatbot, follow these steps:

1. Clone the repository:
   ```sh
   git clone <repository-url>
   cd personal-ai-companion-chatbot
   ```
2. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
3. Set up the **Groq API Key**:
   - Create a `.env` file and add your API key:
     ```
     GROQ_API_KEY=your_api_key_here
     ```
4. Run the chatbot application:
   ```sh
   streamlit run app.py
   ```

## Usage
1. Open the chatbot in your browser.
2. Start a conversation by typing a message.
3. The chatbot will process your input and respond accordingly.
4. Enjoy an interactive, personalized AI chat experience!
